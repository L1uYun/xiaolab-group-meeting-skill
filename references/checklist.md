# xiaolab-checklist

Use this checklist before delivering a deck built with the xiaolab skill.

## Output Contract

- The final deliverable is one directly usable HTML file.
- If images are needed, they live beside the HTML or in a sibling `images/` directory.
- Do not deliver the internal template references as the user's final output.

## Visible Cleanliness

- No placeholder prose remains on visible slides.
- No template notes, remarks, or teaching text appear on the page.
- No `{{title}}`-style visible placeholders remain.
- No “core / components / reference” meta-language appears on the slide.

## Brand Layer

- xiaolab logo loads correctly.
- Hunan University logo loads correctly.
- National Supercomputing Center in Changsha logo loads correctly.

## Navigation

- Left/right key navigation works.
- `F` fullscreen works.
- `ESC` overview works.
- Overview cards expose only clean page navigation information.

## Layout Quality

- The page count matches the user's actual request.
- Text does not collide, clip, or wrap awkwardly.
- Images load locally and are not broken.
- Large whitespace supports reading rhythm instead of hiding weak structure.

## Delivery Judgment

If the user asked for “a deck” or “a PPT”, ask:

`Can they open one HTML file and present from it immediately?`

If the answer is no, the output contract is wrong.
