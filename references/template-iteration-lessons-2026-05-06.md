# xiaolab-template-iteration-lessons-2026-05-06

本页只留仍有复用价值的收束结论。

## 已定边界

### 1. 模板默认应尽量留空

HTML deck 本体不应预置：

- 示例文案
- 教学提示语
- `{{主标题}}` 这类可见占位符文案
- 默认四格数字
- 默认三栏计划
- 默认判断依据列表

可保留：

- 极少数封面识别字段
- 空文字区
- 空图片区
- 布局骨架

结论：**空白优于伪内容。**

### 2. 原则不应上屏

这些东西应写入 skill / references，而不是出现在可见页面中：

- “前两三页够用时……”
- “这页只有在……时才用”
- `核心页 / 参考页` 的分类说明
- `备注：……` 一类使用提示

适用位置：

- SKILL.md
- references/
- 提交说明

不适用位置：

- slide canvas
- ESC 概览卡正文
- 默认导航标题

### 3. overview 也要清洁

ESC 概览不应抓取：

- 备注
- notes
- 页面正文摘要
- 占位符说明
- 核心/参考分类话术

默认只保：

- 页码
- 页名
- 真正存在的主标题（若有）

### 4. 样式应组件化，不应语义页膨胀

不要靠不断新增“某某页”解决需求。

应优先抽象为可拼装组件：

- 单列文字区
- 双列图文
- 双图对照
- 三栏带
- 四格媒体区
- 上下分栏
- 左重右轻 / 右重左轻
- 无框流程带
- 无框对照区

结论：**更多组件，少些语义页。**

### 5. 默认少框

框、卡片、面板、对比框、流程框、图片框，都只应作为可选样式。

默认模板不应预铺：

- 大色块 panel
- 列表点位
- 卡片底色
- 虚线图片框
- 流程箭头装饰
- dots 导航残留 UI

### 6. 清稿验收点

必须检查：

- 标题区、章节页、内容卡片背后，不得有任何可辨识文字残影
- 不得残留模板说明字、占位提示语、母版浅灰大字
- 第七页等对照页，不得残留默认列表点位
- 背景只许：纯色、几何形、线条、低对比渐变
- 不许：可辨中文、英文、占位说明、半透明大字
